# Pop It!

My submission for Option A (Build a Web Toy) for the Technical Domain - Web Dev track in the SRM Github Community Club.

**Live Demo:** https://pop-it-github.vercel.app  
**Demo Video:** https://youtu.be/XtXvQniVhNQ

## About the project
I wanted to make something completely useless but actually kind of addictive. It's basically an infinite "whac-a-mole" game but with bubbles. As your score goes up, the bubbles disappear faster and faster until it gets super stressful. 

Built using only plain HTML, CSS, and JavaScript. No frameworks or external libraries used at all.

## Features
- Infinite gameplay (gets faster based on your score).
- Glassmorphism UI with a moving gradient background.
- Full dark mode and 5 different color themes.
- Saves your high score and theme preferences to local storage.
- 4 Audio files for game immersion.

## Easter eggs
I had a bit of extra time so I hid some secrets:
- If you sit on the start screen for too long, a sassy bunny pops out from random sides of the screen to yell at you.
- If you drop your streak, the bunny gets sad. Click him before he hides for a +25 score bonus.
- Try clicking the main title 5 times fast.

## How to run locally
1. Clone the repo or download the zip, (you can always just play around in the live demo!).
2. Open `index.html` in your browser.
3. That's it!
